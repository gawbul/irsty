A modern IRC client for your terminal.

Irsty speaks today's IRC: chat history, replies, reactions and typing, bouncers and SASL. It keeps the keys you know from irssi and WeeChat, and it's one small binary for Linux, macOS and Windows.

brew install gawbul/tap/irsty
Other ways to install

Every screen on this page is drawn by Irsty's own code.

Coming from irssi or WeeChat

Irsty starts with irssi's keys. Set keymap = "weechat" under [ui] for WeeChat's, and rebind anything with /bind.

Your settings live in one config.toml. Commands like /server add and /set write it for you and keep your comments, and passwords stay in your keyring or a password manager. Every key and every command is in the docs.

Scripting with Luau

Scripts react to messages and joins, add commands, print and set timers. Each runs in a sandbox of its own: no files, no network and no programs, with limits on time and memory.

A script acts for you on the network only if you allow it. This one, /slap, needs allow = ["send"] in its [[script]] entry.

The scripting guide covers the whole API.

-- slap.luau: /slap <nick> slaps someone with a large trout, irssi-style.
-- It acts for you, so it needs the send capability:
--
--   [[script]]
--   path = "scripts/slap.luau"
--   allow = ["send"]

irsty.command("slap", function(args, here)
    local nick = args:match("^%s*(%S+)")
    if not nick then
        irsty.print("Usage: /slap <nick>")
        return
    end
    if not here or not here.buffer then
        irsty.print("/slap needs a channel or query")
        return
    end
    irsty.exec("/me slaps " .. nick .. " around a bit with a large trout")
end)

Accessible by design

irsty --plain is a line-by-line interface for screen readers and braille displays. Nothing is drawn: new lines are printed as they arrive, mentions from other windows too, and you type on an ordinary line.

Accessible mode keeps the full-screen interface but makes it one column of plain ASCII, and puts words beside anything shown only by colour. The high-contrast theme needs no colour at all.

Install

Homebrew, on macOS and Linux
brew install gawbul/tap/irsty
Shell installer, on macOS and Linux
curl --proto '=https' --tlsv1.2 -LsSf https://github.com/gawbul/irsty/releases/latest/download/irsty-installer.sh | sh
Scoop, on Windows
scoop bucket add gawbul https://github.com/gawbul/scoop-bucket
scoop install gawbul/irsty
PowerShell installer, on Windows
powershell -ExecutionPolicy Bypass -c "irm https://github.com/gawbul/irsty/releases/latest/download/irsty-installer.ps1 | iex"
Nix, on Linux and macOS
nix profile install github:gawbul/irsty
Cargo, anywhere Rust builds
cargo install irsty

Arch Linux: a PKGBUILD is in the repository, and the AUR package is on its way. The releases also have archives for each platform, with the man page and shell completions.

Then run irsty, and add a network with /server add.
